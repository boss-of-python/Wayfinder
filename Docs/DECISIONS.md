Accepted baseline: owner blueprint v1.0 and implementation handoff. Work remains on

## 2026-10-14 — D002: evidenced, conservative editor/package pins
Pin **6000.3.0f1 (d1870ce95baf)**, not an invented/latest patch. Unity's public
InputSystem_Warriors sample at `b7945bd71c7d47cc1876dd1d046c811fa3a311a4`
records that editor with URP 17.3.0, Input System 1.16.0, Test Framework 1.6.0,
and uGUI 2.0.0. See `Evidence/dependency-sources.json` for the selected lock entries.
Addressables 2.7.6 and Localization 1.5.9 metadata were retrieved from versioned
package mirrors; their declared editor minimums fit the baseline, but integration
is NOT established by metadata alone. A dependency-closed lock was assembled from
those sources, not generated by an editor here. Unity must resolve it and any lock
rewrite must be reviewed/committed before the M0 gate passes.

This is an initial reproducibility pin, not a security/support certification. Audit
6.3 patch advisories on an unrestricted workstation before production use. Upgrade
only with a recorded decision and clean import/build/test evidence. The sandbox
cannot reach Unity's download/package hosts. No Unity license is present.

Do not import the sample's analytics, multiplayer, collaboration, DOTS, or IDE
packages. UnityWebRequest modules are transitive Addressables capabilities, not
application network calls; runtime remote content is prohibited. Cinemachine is
not selected yet: its use is conditional on M1 camera tests in the blueprint.
Localization and Addressables are pinned foundations, not completed systems.

## 2026-10-14 — D003: source-authored foundation assets
Commit actual minimal Bootstrap/Title scenes, input actions, pipeline/renderer
settings, metadata and small assemblies. An explicit **Wayfinder > Prepare M0**
editor command normalizes configuration through Unity APIs and assigns assets.
No automatic destructive scene regeneration on import. Runtime title UI is built
with uGUI to keep hand-authored scene references small and reviewable; it is a
tracked placeholder, not final UI or accessibility certification.

Core has no Unity reference. Platform owns input/lifecycle adapters; Presentation
owns title UI; a Composition assembly wires them. Editor code never ships.
Menu overlays and lifecycle holds own independent disposable pause tokens.
No save slots, New Game, or Continue path is pretended to exist in M0. They are
explicitly unavailable until M2's creation-before-movement save guarantee exists.

## 2026-10-14 — D004: build/CI boundaries
Python structural checks run without Unity. They cannot establish C# compilation,
physics, rendering or native behavior. Unity tests and build commands are supplied
for a licensed owner workstation; native outputs stay in ignored `Artifacts/`.
No signing secrets, account details, license files, or generated binaries go in Git.
The CI Unity job is opt-in on an owner-managed runner; no unapproved cloud license
or hosted-runner spend. M0 gate remains Blocked until actual Unity and smoke evidence.
