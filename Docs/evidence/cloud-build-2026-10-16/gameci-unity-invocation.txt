#
# 1. dist/platforms/ubuntu/steps/build.sh:218-223 creates the build directory before the build
#    (`mkdir -p "$BUILD_PATH_FULL"`) and ends with `ls -alh` on it, and
#    dist/platforms/ubuntu/steps/runsteps.sh takes the step's exit code from BUILD_EXIT_CODE.
#    A build method that produces no artefact (Setup Project) therefore does NOT fail by itself:
